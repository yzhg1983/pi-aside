      Tools

      For every chat and every site.

      Read page Reads the text of the page.
      Observe page Lists the links, buttons, fields, and headings on the page.
      Act on page Clicks, types, scrolls, and goes to pages of the same site; follows links to other sites you allow.

      Ask: pi asks once per answer for each site.
      On: pi may click and type without asking, also on buttons such as Submit or Delete.

      Run script Runs JavaScript that pi writes, on the page.

      A script runs as you on the site, with your login: it could read and change anything you can there, and send what it reads to other sites. Ask: pi shows each script first; "For this answer" or "For this chat" lets the next ones on that site run without asking until the answer, or the chat, ends (a new chat, Chrome closing, or a change here). On: scripts run without asking. Stop does not end a script that is already running.

      Needs Chrome's "Allow User Scripts" for pi
      Screenshot page Captures what the tab shows, as an image.

      The image shows what is on screen, also what you typed into fields, and goes to the model's provider. pi may scroll the page first, also with Act on page Off. Works after you open pi on the site with its toolbar button, menu, or shortcut, or on any site when Chrome allows pi on all sites (Settings > Advanced > Sites).

      5 to 200, for all page tools together.
